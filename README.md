# Monovision Studio

A simple web project built using HTML and CSS. The main goal of this project is to build a personal portfolio.

## 🔧 Technologies Used

- **HTML5** — Page structure
- **CSS3** — Styling and layout

## 💻 Project Structure

```bash
src/
├── index.html           # Main HTML file
├── css/                 # CSS files
├── icons/               # Project icons
├── img/                 # Project images
└── logo/                # Project logos
```

## 🚀 How to Run
- ### Clone the repository:
  ```bash
  git clone https://github.com/your_username/project-name.git
  ```
- ### Open the index.html file in your browser:
  - Double-click the file
  - Or use Live Server in VS Code
